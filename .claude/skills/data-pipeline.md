# TrafficFM Data Pipeline Reference

Answer questions about how data flows through this benchmark — from raw H5 files to what each model type receives for training and test evaluation.

## Raw Data Source

All traffic data originates from `data/LargeST/{region}/{region}_his_{year}.h5`:
- A pandas DataFrame of shape `(T, N)` where T = timesteps, N = sensors
- 15-minute intervals, resampled with `.resample("15T").mean().round(0)`
- Regions: `sd` (716 sensors), `gba` (2352), `gla` (3834), `ca` (8600)
- Years available: SD has 2018+2019; GBA/GLA/CA currently only 2018

Actual files live in `/scratch/bcqc/tliao2/TrafficFM/data/LargeST/`.  
`benchmark/data/{region}` and `benchmark/gnn/data/{region}` are symlinks to `dataset/LargeST/baseline/{region}`.

---

## Split Ratios (all model types use identical boundaries)

For a single year (T ≈ 35040 steps = 8760h × 4):

```
|←────── 60% train ──────→|←── 20% val ──→|←── 20% test ──→|
 t=0                    t=21024         t=28032           t=35040
```

- `num_train = round(T * 0.6)`
- `num_val   = round(T * 0.2)`
- test = remaining ~20%  (≈ 7008 steps ≈ 73 days)

This split is computed identically by both data generation scripts:
- `generate_dataset_for_training.py` (→ GNN baseline npz)
- `generate_data_for_gift_eval.py`   (→ FM/SSM arrow format)

## Two Storage Formats (same underlying split)

### Format A — GNN baseline (`dataset/LargeST/baseline/{region}/{year}/`)

Generated by `scripts/data_processing/LargeST/generate_dataset_for_training.py`:

```
his.npz          # data: (T, N, 3)  [speed, time-of-day, day-of-week]
                 # mean, std: computed from training rows only
idx_train.npy    # integer anchors into data for train windows
idx_val.npy      # integer anchors for val windows
idx_test.npy     # integer anchors for test windows
```

Anchors are **center-of-window** pointers: for anchor `t`, the input window
is `data[t + x_offsets]` (last 12 steps ending at t) and label is
`data[t + y_offsets]` (next 12 steps). `x_offsets = [−11..0]`, `y_offsets = [1..12]`.

Normalization: global z-score using **train-split mean/std only** (saved in his.npz).

Also needs: `{region}_rn_adj.npy` — adjacency matrix `(N, N)` for graph convolutions.

### Format B — gift_eval arrow (`dataset/LargeST/gift_eval/`)

Generated by `scripts/data_processing/LargeST/generate_data_for_gift_eval.py`:

```
gift_eval/
  {region}/{year}/15T/          ← test split as HuggingFace arrow dataset
  {region}_train/{year}/15T/    ← train split
  {region}_val/{year}/15T/      ← val split
```

Each arrow dataset is a list of N series records:
```python
{
  "item_id": "sensor_id",
  "start": "2019-01-01T00:00:00",   # timestamp of first row in this split
  "freq": "15T",
  "target": [float, ...],            # raw (un-normalized) speed values
  "past_feat_dynamic_real": [[tod...], [dow...]]  # optional time features
}
```

No pre-normalization — each model normalizes per-window at inference time.

## What Each Model Type Receives

### GNN (AGCRN, DCRNN, GWNet, STGCN, etc.)

**Training/Val**: `DataLoader` iterates over `idx_train` / `idx_val` anchors,
assembles `(B, 12, N, 3)` input and `(B, 12, N, 1)` label batches on the fly.

**Test**: Uses `idx_test` anchors, but **re-aligned to gift_eval windows** via
`_gift_eval_anchors()` in `dataloader.py`. This function queries the gift_eval
`Dataset` object to get the exact anchor offsets that `common.eval()` uses,
so GNN and FM/SSM see **identical non-overlapping test windows**.

The alignment logic (from `dataloader.py`):
```python
seq_start     = T - (inp_len + pred_len)
first_inp_len = inp_len - (windows - 1) * pred_len
anchors = [seq_start + first_inp_len + i*pred_len - 1 for i in range(windows)]
```

Entry point: `uv run --project gnn python -m gnn.{model} --dataset SD --years 2018 --mode train`  
Working dir: `benchmark/` (AGCRN) or `benchmark/gnn/` (most others — affects `os.getcwd()/data/` path resolution)

### SSM (LRU, S4, Mamba-v2)

**Training**: reads `{region}_train/{year}/15T` arrow dataset via gift_eval `Dataset`.
`make_windows()` samples up to `windows_per_sensor` (default 3000 for SD, 1000 for GBA)
windows per sensor, spaced evenly across the train split. Per-window z-score normalization
using that window's own mean/std (no global scaler).

```python
# SSM window sampling (lru.py / s4.py / mamba.py)
indices = np.linspace(0, max_start, windows_per_sensor, dtype=int)  # evenly spaced
ctx = target[s : s + context_length]   # input  (default context_length=96 steps = 24h)
fut = target[s + context_length : s + context_length + pred_len]    # label
# normalize per-window: (x - mean) / std
```

**Val**: same `make_windows()` on `{region}_val/{year}/15T`, used for early stopping.

**Test (eval)**: after training, uses `common.eval()` with `{region}/{year}/15T` (test split) —
**same pipeline as FM models**, so results are directly comparable.

Entry point: `BENCHMARK_CONFIG=configs/mamba_train.yaml uv run --project fm/moirai python ssm/lru.py --year 2018`

### FM (Moirai2, Chronos, Sundial, Kairos, TimesFM, FlowState)

**Zero-shot**: no training. `common.eval()` directly feeds test-split windows.

**Test**: `common.eval()` iterates `dataset.test_data` which generates sliding windows
from the tail of each series in `{region}/{year}/15T`. Window count is controlled by:
```python
dataset.windows = min(max(1, ceil(0.1 * min_series_length / pred_len)), 20)
```
Windows are **non-overlapping**, spaced `pred_len` steps apart, working backwards from the end of the series.

Entry point: `BENCHMARK_CONFIG=configs/fm_{region}_{year}.yaml uv run --project fm/moirai python -m fm.moirai.moirai2`

---

## Test Window Guarantee: No Overlap, All Models Identical

The test split covers the **last 20% of the timeline** (same absolute timestamps for all models).

gift_eval generates test windows working **backwards from the end** of each series:
- Last window: label ends at the last timestep T
- Each preceding window: shift back by exactly `pred_len` steps
- Total windows: `min(ceil(0.1 × T / pred_len), 20)` per series

For SD/2019/15T (T=7008, pred_len=3/6/12):
- short (pred_len=3):  20 windows, each 3 steps apart → covers last 60 steps of test
- medium (pred_len=6): 12 windows, 6 steps apart → covers last 72 steps
- long (pred_len=12):  6 windows, 12 steps apart → covers last 72 steps

GNN's `_gift_eval_anchors()` replicates this exact anchor arithmetic, so all three
model families evaluate on **the same set of non-overlapping windows** drawn from the
same 20% test period.

## Adding a New Region

**Important**: The intermediate `{region}_his_{year}.h5` files in scratch were written with
pandas < 2.0 and cannot be read by the current environment (pandas ≥ 2.0 drops support for
`datetime64[ns]` index in HDF5). Always regenerate from the raw CA H5 files using
`process_dataset.py` first — do NOT try to read the pre-existing intermediate H5 files directly.

The raw files are at `/scratch/bcqc/tliao2/TrafficFM/data/LargeST/raw/ca_his_raw_{year}.h5`
(readable with all envs). Everything else is derived from them.

**Step 0 — Regenerate intermediate H5 from raw** (run from `/scratch/bcqc/tliao2/TrafficFM/`):
```bash
# Removes and re-creates {region}_his_{year}.h5 for gba/gla/ca
uv run --project /u/tliao2/TrafficFM/benchmark/fm/moirai \
    python /u/tliao2/TrafficFM/scripts/data_processing/LargeST/process_dataset.py \
    --year 2018
# Repeat for --year 2019
```

**Step 1 — GNN baseline** — run from `/scratch/bcqc/tliao2/TrafficFM/`:
```bash
uv run --project /u/tliao2/TrafficFM/benchmark/fm/moirai \
    python /u/tliao2/TrafficFM/scripts/data_processing/LargeST/generate_dataset_for_training.py \
    --dataset gla --years 2018
# output: dataset/LargeST/baseline/gla/2018/{his.npz, idx_*.npy}
```
Then:
```bash
# symlink into benchmark paths
ln -s /scratch/bcqc/tliao2/TrafficFM/dataset/LargeST/baseline/gla/2018 \
      /u/tliao2/TrafficFM/dataset/LargeST/baseline/gla/2018
ln -s /u/tliao2/TrafficFM/dataset/LargeST/baseline/gla \
      /u/tliao2/TrafficFM/benchmark/data/gla
ln -s /u/tliao2/TrafficFM/dataset/LargeST/baseline/gla \
      /u/tliao2/TrafficFM/benchmark/gnn/data/gla
# copy adj matrix
cp /scratch/bcqc/tliao2/TrafficFM/data/LargeST/gla/gla_rn_adj.npy \
   /u/tliao2/TrafficFM/dataset/LargeST/baseline/gla/
```

**Step 2 — gift_eval format** — run from `/scratch/bcqc/tliao2/TrafficFM/`:
```bash
uv run --project /u/tliao2/TrafficFM/benchmark/fm/moirai \
    python /u/tliao2/TrafficFM/scripts/data_processing/LargeST/generate_data_for_gift_eval.py \
    --dataset gla --years 2018 --overwrite
# output: dataset/LargeST/gift_eval/gla/2018/15T/ (+ gla_train/ + gla_val/)
```
The `dataset/LargeST/gift_eval/` directory is already symlinked/shared — no extra step needed.

**Step 3 — Config**:
```bash
cp /u/tliao2/TrafficFM/benchmark/configs/fm_sd_2018.yaml \
   /u/tliao2/TrafficFM/benchmark/configs/fm_gla_2018.yaml
# edit: change short_datasets and med_long_datasets to "gla/2018/15T"
```

**Step 4 — SLURM scripts**: Use the generator script at
`/tmp/.../scratchpad/gen_scripts.py` or copy and adapt existing GBA scripts.
